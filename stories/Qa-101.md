# QA-101: Shopper can log in and manage the cart

As a shopper, I want to log in and add products to my cart so that I can check out.

## Acceptance Criteria
AC1. A valid user (standard_user / secret_sauce) lands on the Products page after login.
AC2. A locked-out user (locked_out_user) sees an error explaining the account is locked and stays on the login page.
AC3. A wrong password shows an error that username and password do not match.
AC4. Adding a product to the cart shows a cart badge with count 1; removing it clears the badge.
AC5. At checkout, submitting the information form with an empty First Name shows a "First Name is required" error.
